/* ═══════════════════════════════════════════════════════════════════════
   RESPONSIVE — Dashboard Grid (Mobile / Tablet / PC / Wide)
   ─────────────────────────────────────────────────────────────────────
   Estrategia:
   • Mobile (<768px):  Stack vertical (flex column).
   • Tablet (≥768px):  2 columnas equilibradas.
   • Desktop (≥1024px):3 columnas con sidebar de Score sticky.
   • Wide (≥1440px):   Mismo layout, max-width contenido para no estirar.
   ─────────────────────────────────────────────────────────────────────
   Áreas nombradas (grid-template-areas) para que el orden visual NO
   dependa del orden del HTML — más mantenible y legible.
   ═══════════════════════════════════════════════════════════════════════ */
